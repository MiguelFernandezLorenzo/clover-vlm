## State: **Reach Object**

---

## 🎯 GOAL
Move precisely toward the desired object until you are close enough to stop and describe it.

---

## 🧠 POLICY RULES

- Advance gradually toward the object using small forward steps (`A1`).
- If the object is not centered, use small rotational adjustments (`B1`, `C1`) to align it in the center of the frame.
- Use lateral movements (`D1` or `D2`) **only** if the object is close and slightly off-center.
- If the object appears fully on one side of the image (more than 40% off-center) or looks like is almost out of view:
  - prioritize lateral rotations (`C1` if the object is on the right side, `B1` if the object is on the left side)
  - to bring it closer to the center of view before proceeding forward.
- Consider the object “close enough” if:
  - It fills at least 40% of the image width **or** its top and bottom edges are cropped in the view,
  - And it appears roughly centered (within ±20% from the horizontal center).
- If the object is very tall or vertical (like a mirror) with top/bottom cropped, do not keep adjusting alignment but move forward until close.
- If any of these conditions are not met, continue approaching or adjusting alignment.
- If the object disappears from view for **2 or more consecutive steps**, you MUST:
  - immediately transition to `Search Object`
  - return movement = `E`
  - and never keep rotating or moving forward in `Reach Object` if the object is missing.
- Do not continue forward if only a flat wall or undistinguished surface is visible.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command from the list below:

### A. Forward movement:
- `A1`: move forward 10 cm

### B. Left rotation:
- `B1`: rotate 15°

### C. Right rotation:
- `C1`: rotate 15°

### D. Lateral movement:
- `D1`: move 10 cm left
- `D2`: move 10 cm right

### E. Transition:
- `E`: issue exclusively when transitioning to `Search Object` after the object is missing for 2+ steps or when transitioning to `Describe Object`

---

## 🔄 OUTPUT STATE RULES

Choose the next FSM state:

- `Reach Object`: if the object is still visible but not yet reached or aligned.
- `Describe Object`: if the object is approximately centered, large, and visually close based on the above conditions.
- `Search Object`: if the object has disappeared from view for 2 or more consecutive steps, no recognizable object is in frame, or visual tracking is lost.

---

## ⚠️ NOTES

- Avoid overshooting: stop once the object appears large and approximately centered.
- Do not rotate if the object is already aligned.
- If the object disappears from view for 2+ steps, stop and transition back to `Search Object` with movement `E`.
- If the output state is `Describe Object`, always move with `E`.
- Prioritize lateral adjustments over forward movement if the object is strongly off to one side.
