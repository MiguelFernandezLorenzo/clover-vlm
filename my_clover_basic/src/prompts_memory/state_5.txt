## State: **Describe Object**

---

## 🎯 GOAL
Stop all movement and describe the current position and appearance of the identified object.

---

## 🧠 POLICY RULES

- Do not move the robot. Only assess and describe the visible object in the image.
- Focus on characteristics such as:
  - Location in the image (center, left, right, near, far)
  - Size (small, large, full-frame)
  - Orientation or context (e.g., on table, near wall)
- If the object is partially outside the frame or occluded, mention this clearly.

---

## 🕹️ MOVEMENT COMMANDS

Only return **ONE** movement command from the list below:

### E. Stop:
- `E`: stop movement (robot is already in position)

---

## 🔄 OUTPUT STATE RULES
